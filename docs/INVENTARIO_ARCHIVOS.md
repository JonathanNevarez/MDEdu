proyecto se mantuvo intacto; su copia local aparece en el inventario. Posteriormente

documentación. El paso Git añadió .gitattributes y la lista de candidatos al primer
commit. `.git`, `backend/target`, `frontend/node_modules`, `frontend/dist` y las
instalaciones/cachés del usuario no forman parte de esta lista.
